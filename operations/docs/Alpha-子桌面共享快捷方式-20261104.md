已完成共享原数据的子桌面启动实测；**主、子桌面同时多开尚未实现**。本机 Alpha 0.3.5 自带单实例锁，另一端启动时会退出新进程并尝试唤醒已有窗口。当前 Alpha 保留在 Anode Session 7，主进程 PID 186344。

## 使用

在 Anode 子桌面内打开 [Alpha-Shared-In-Anode.lnk](<F:/AI infrastructure/agent-Windows-operation/launchers/Alpha-Shared-In-Anode.lnk>)。重复点击会复用当前窗口。若要回主桌面使用，先在子桌面正常退出 Alpha；如果关闭窗口只是收进托盘，应从托盘菜单退出，再打开原来的 Alpha 图标。

这个入口不会退出其他会话的应用，也不会启动或重建 Anode 会话。主桌面仍运行 Alpha 时，入口会提示先保存并正常退出。Alpha 升级后，入口的版本校验会要求重新核对数据目录和启动行为。
