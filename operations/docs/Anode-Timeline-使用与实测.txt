使用 Timeline
工具栏 Timeline 打开或收起右侧面板。
下拉框选择 All activity / Agent / Human；点击记录查看时间、动作、结果、耗时。
含截图的记录会显示预览。截图来自 Agent 已经请求的截图，不是每步自动截屏或录像。
Human 只覆盖通过这个 Viewer 的实际输入与接管/归还；应用内部后台操作不在覆盖范围。
正文输入只记录数量；ActiveX 没有字符消息时显示 Keyboard input: N key events，不能等同于最终输入字符数。
日志中的 ok 表示工具调用返回成功，不保证应用真正收到输入。仍须观察目标应用确认。
截图可能包含屏幕上的文字；事件摘要不保存键入正文、密码、令牌或命令参数。
无自动回放，无自动删除日志和截图。
