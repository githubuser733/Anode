核查日期：2026-10-31。三个快捷方式已在 Anode Session 8 实际启动，并验证了最小化后再次点击可恢复已有应用窗口。它们与 WorkBuddy 入口一样，供 **Anode 子会话内** 使用。

| 软件 | 项目 launchers 中的入口 | 配置与登录复用方式 |
|---|---|---|
| Grok Bot 0.78.1 | `GrokBot-In-Anode.lnk` | 沿用先前实测的 Anode 运行目录和登录副本；已有测试会话可见 |
| TRAE CN 3.4.11 | `TRAE-CN-In-Anode.lnk` | 默认 Agent；每次启动读取主配置，直接共用本机任务数据和扩展；身份状态首次从主配置建立 |
| OpenCode 2.2.2 | `OpenCode-In-Anode.lnk` | 独立桌面运行目录，共用原有认证、业务数据库、配置和本机后台服务；已显示已有历史会话 |

使用步骤：

1. 打开项目 `launchers\Anode-Timeline-1920x1080.lnk`，显示现有 Viewer。
2. 在 **子会话的文件资源管理器** 中打开 `F:\AI infrastructure\agent-Windows-operation\launchers`。
3. 双击需要的入口。软件未运行时启动新实例；已运行时恢复子会话中的已有窗口。
4. 主桌面的普通软件入口继续供主桌面使用。本项目这三个快捷方式在主桌面会显示“Open this shortcut INSIDE the Anode child session”，不会误启动另一个主桌面实例。

Grok Bot 沿用首次建立的登录副本，聊天记录不能假定实时同步。TRAE 已改为共用本机任务数据；模型、MCP 和普通偏好每次点击入口时读取主配置，子会话单独覆盖默认 Agent 模式。OpenCode 的业务数据也共用同一目录。各软件的窗口仍属于各自 Windows 会话，不能把活窗口直接拖到另一会话。

- `config/multiopen-apps.json` 保存安装路径、已验证版本、运行目录和共享目录。
- `scripts/Start-AppInAnode.ps1:16` 核对已验证版本；第 22 行检查当前 Anode 子会话，第 89 行为 TRAE 查找 Agent 窗口。
