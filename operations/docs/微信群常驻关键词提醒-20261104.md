# 微信群常驻关键词提醒

本机后台通过 Alpha 只读接口检查两个指定群，关键词命中后合并弹出本机通知，并保存 Markdown 摘录。常驻监控不发送微信、不调用摘要模型、不操作键盘。输入法冲突排查继续暂停。

22 时后已升级为原生托盘入口，采用用户选定的 2 秒检查、首次命中立即提醒。当前版本与最新验证见 [托盘与检查频率](微信群托盘与检查频率-20261104.md)；下方“本轮验证记录”保留首次部署时的实测历史。

| 检查间隔 | 2 秒，本机 Alpha MCP 只读查询 |
| 提醒 | 首次发现命中即请求本机提醒；两次通知至少间隔 60 秒，期间后续命中合并 |
| 通知内容 | 各群命中条数；全文摘录在本地 Markdown |
| 重启恢复 | 保存各群读取进度和去重记录，按 5 分钟窗口补读 |
| 自动保活 | Windows 计划任务每分钟检查，登录后也触发 |

没有新增命中就不弹窗。首次启用以前的旧消息不当作新提醒；停机后补读的消息可能早于弹窗时间。旧美卡群不在白名单中。

## 日常操作

项目目录：`F:\AI infrastructure\agent-Windows-operation`。

- 启动：双击 `launchers\微信群关键词监控-启动.lnk`。
- 停止：双击 `launchers\微信群关键词监控-停止.lnk`。读取进程会在当前查询结束后正常退出，托盘保留暂停状态，停止状态持久保存，保活任务同时禁用。托盘右键“退出并停止监控”可同时退出图标。
- 查看报告：打开 `artifacts\wechat-resident\reports`，每次提醒对应一个 `.md` 文件。
- 查看状态：在本项目 PowerShell 中运行下面命令。

```powershell
.\launchers\WeChat-Resident.cmd Status
```

正常输出包括 `enabled=true`、`running=true`、`healthy=true`；`counts` 列出新增、命中、等待提醒、系统已显示和结果不确定的通知数。`health.at_ms` 是最近检查的时间。停止后 `enabled=false`、`running=false`；网络请求尚在收尾时可能短暂仍显示运行。

```powershell
.\launchers\WeChat-Resident.cmd TestNotification
```

此命令用隔离的本地模拟数据检查弹窗，不向群里发测试消息，也不读取 Alpha。通知标题含“测试”，正文含“本地模拟测试”。正常返回 `state=shown` 和测试报告路径；该回执只代表 Windows 报告弹窗显示，不代表用户已经阅读。测试状态存入 `artifacts\wechat-resident-tests\live-*`，不影响真实进度。

跨工作区可按绝对路径调用：

```powershell
& 'F:\AI infrastructure\agent-Windows-operation\launchers\WeChat-Resident.cmd' Status
```

双击无参数的 `WeChat-Resident.cmd` 也执行状态查询；终端调用便于保留输出。`Start`、`Stop` 是对应的命令行操作。

## 运行条件与边界

Alpha 保持在主桌面并提供可用的本地只读服务；Anode 子桌面需已经登录且 ready。服务按实测主桌面会话启动，不会自行启动或重建 Anode、退出任何应用、触发共享剪贴板或键盘输入。当前工作流使用本机已有身份；切换 Alpha 账号或更改监控白名单会停止推进并要求重新核对。

Alpha 暂时不可用时保留检查点，按 10、20、40 秒等退避，最多间隔 5 分钟重试。恢复时重新加载认证和核对群身份。每次回看最近 5 分钟用于覆盖短期延迟；超过此范围才进入 Alpha 的消息可能漏报。窗口超过 2000 条或分页异常时记录覆盖缺口，不以截断数据冒充完整读取。异常详情见 `artifacts\wechat-resident\runs\<运行目录>\errors.jsonl`。

通知前先持久登记对应消息，避免重启后重复弹窗。若 Windows 通知结果不确定，计入 `notificationsUncertain`，详细报告仍保留，不自动反复重试。状态和报告没有自动删除规则；清理需另行按项目删除授权要求处理。

核心进程与 Windows 保活任务不依赖 Codex 对话持续打开。Codex 小时健康检查 `automation-2` 已按用户要求于 2026-11-05 停用；Windows 本地保活保持启用，消息匹配仍由本地程序执行。停用的是额外的 Codex 异常核查层，不是采集或通知进程。
