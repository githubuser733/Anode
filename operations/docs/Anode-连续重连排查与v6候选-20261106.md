## 原因和对照

v5 已在 2026-11-06 07:35 保存用户在 Windows 原生窗口输入的凭据。07:39:58 的普通 Reconnect 成功复用；07:40:03 的下一次失败，显示 `Sign-in failed (code -1)`。

Windows RemoteConnectionManager 1149 在失败前记录身份验证成功，随后 RdpCoreTS 报扩展断开码 258。旧连接的 LocalSessionManager 24（完成断开）发生在新连接认证和错误之后。依据 [Microsoft OnLogonError 文档](https://learn.microsoft.com/en-us/windows/win32/termserv/imstscaxevents-onlogonerror)，-1 是拒绝访问，不等于密码无效；密码无效有单独代码。258 的本机说明是客户端访问许可证协商失败。未修改许可、NLA 或安全策略。

有界诊断复用同一 RDP 控件、同一已存凭据、同一 Session 13，不结束会话、不输入键盘。只改变断开后的等待：
