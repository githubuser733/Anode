## v5 行为

1. 仅显式 `--remember-login` 启用。首次由用户在 Windows 窗口输入当前 Windows 账户密码并选择保存。
2. 登录成功后写入 Anode 专用条目；取消、失败、仅建立传输连接、未勾选保存均不写。状态会明确显示 `saved`、`reused`、`not-saved`、`save-failed` 或 `login-failed`。
3. 后续启动／普通 Reconnect 读取本机、当前 Windows SID、当前 Anode channel 对应的最新条目，设置 RDP 用户名、域和官方只写密码接口。此机制的真实子会话效果仍待验收。
4. 密码会短暂进入本机 Anode 的原生内存，随后清零自管缓冲区；RDP 控件负责其内部副本。密码不进入源码、命令行、配置、聊天、MCP 或日志。不能继续把新版称为“Anode 完全接触不到密码”。
5. Windows 凭据管理器负责持久保管；不新增明文密码文件、不设置 Windows 开机自动登录、不降低 NLA／策略。不同 Windows 用户不共享；相同用户下可跨工作区使用。相同 Windows 用户的本地进程仍属于同一信任范围。
6. 保存使用新版本条目，保留旧凭据，不自动覆盖或删除。失败不自动反复尝试；由用户点 Sign in 修复。
